# Visual and icon provenance

The visual system was constructed in this repository from these rules:

- deep indigo surfaces with apricot action facets;
- modern system sans-serif typography;
- 8–12 px symmetric corner radii;
- compact information hierarchy and visible numeric labels;
- 24-unit monoline glyphs with open corners and clipped inner strokes;
- a rounded bowl and four-point spark brand mark.

All path data in `src/components/Icons.tsx` and `android/app/src/main/res/drawable/vita_launcher_icon.xml` was drawn for this project. No icon font or drop-in icon library is bundled. Future icon changes must preserve source notes and must not trace screenshots or proprietary assets.

The README screenshots in `docs/assets/screenshots/` are rendered from Vita's own React interface with synthetic demonstration data. They contain no device capture, personal record, credential, or third-party artwork.
