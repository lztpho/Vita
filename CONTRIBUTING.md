# Contributing

Contributions are welcome when they preserve Vita's local-first privacy and security boundaries.

1. Do not submit credentials, signing material, personal data, screenshots containing user data, or unrelated repository history.
2. Add SPDX headers to source files and document third-party origins.
3. Run the Web tests/build, Android unit tests/Lint/build, dependency scans, license inventory, and SBOM generation before submitting.
4. Do not add telemetry, an official proxy, plaintext secret storage, HTTP endpoints, redirect following, or destructive database migration fallback.
5. Sign every commit using the Developer Certificate of Origin: `git commit -s`.

By signing off, you certify the DCO 1.1 statement at <https://developercertificate.org/>.
